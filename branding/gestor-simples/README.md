# Gestor Simples — marca

CRM de gerenciamento de mensalidades. Tagline: **Mensalidades em dia, sem planilha.**

Abra `guia-da-marca.html` no navegador para ver o guia completo.

## Arquivos

| Arquivo | Uso |
| --- | --- |
| `icon.svg` | Ícone do app, favicon, avatar de redes sociais |
| `icon-mono.svg` | Símbolo de uma cor (herda `currentColor`) |
| `logo-horizontal-light.svg` | Logo principal sobre fundo claro |
| `logo-horizontal-dark.svg` | Logo sobre fundo escuro |
| `tokens.css` | Cores, gradiente, fontes e raios como variáveis CSS |

Os logos horizontais usam a fonte Outfit como texto. Para impressão ou uso fora da web, converta o texto em contornos (Inkscape/Figma: "Objeto em caminho").

## Cores

| Nome | Hex | Papel |
| --- | --- | --- |
| Roxo Gestor | `#7C3AED` | Primária: botões, links, foco |
| Rosa Recebido | `#EC4899` | Destaque: pagamento confirmado |
| Azul Ciclo | `#2F6BFF` | Informação: datas, calendário |
| Tinta | `#1E1433` | Texto, fundo escuro |
| Névoa | `#F6F3FB` | Fundo das telas |
| Lilás | `#E9E2F8` | Bordas |

Gradiente: `linear-gradient(135deg, #2F6BFF, #7C3AED, #EC4899)`.

Status: Pago `#12A150` · Pendente `#D98A04` · Atrasado `#E0364F`.

## Tipografia

- **Outfit** (600/700): títulos e logo
- **DM Sans** (400/500/700): textos e interface
- **IBM Plex Mono** (400/500): valores e datas
